# 犬吠埼風は、うどんを愛している

<a href="./cover.jpg"><img width="600" src="./cover-min.jpg"></a>

## あらすじ

うどん屋の開拓のため、散歩へ出かけた勇者部一同を待ち構えていたのは、秘密結社「讃州うどん連合」の本拠地だった。
そして風と友奈は、「うどん大食い大会」の戦いへと身を投じる…。

「犬吠埼風はうどんを愛している」。

ご期待ください。
